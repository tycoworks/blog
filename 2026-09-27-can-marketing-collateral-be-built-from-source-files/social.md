Like many folks, I now do most of my work with Claude Code. Blog posts, strategy docs, and messaging all live in markdown files in Git, alongside a bunch of skills that codify how I work.

The one thing I've struggled with though is collateral. Decks, one-pagers, and battlecards typically live in PowerPoint, which is hard to version control and edit reliably with AI.

So I've been working on a new project, tycoslide. It takes a markdown file as input, and generates an editable .pptx using your existing PowerPoint template. It can also turn your template into an agent skill, so anyone can build on-brand decks with it.

Read more and try it out here: https://www.tycoworks.com/p/marketing-collateral-from-source-files
