# Writing in this repo

Each post has its own folder, named with the date it was first published and a short slug. Inside it:

- `post.md` is the post.
- `plan.md` is the post's plan while it's being written, an Obsidian Kanban board with the reader and answer, the introduction, the points, and the evidence. It's deleted when the post is published.
- `social.md` is the promo copy, as it was posted.
- `video.mov` and the images sit beside them, and `post.md` links to them by file name.

Link to `tycoworks.substack.com`, not `tycoworks.com`. Add each new post to the table in `README.md`, with the newest first.
